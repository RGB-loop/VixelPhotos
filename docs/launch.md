# 宣发准备清单

## 一句话

**Vixel：用一句话找到照片和视频里的那一刻。完全离线，不上传，不需要账号。**

三个支点（按可信度排序，都有本地实测支撑）：

1. **搜得准，也敢说“没有”**：语义 + 图中文字 + 文件名四路融合；库里没有的东西不会硬凑一屏结果（自适应相关性门槛，见 `src/core/search.ts`）。
2. **连视频里的字和人都能搜**：视频按全分辨率帧做 OCR 和人脸识别（招牌、价签、路牌都能搜到）。
3. **真的离线**：渲染进程网络白名单强制拦截（只放行地图瓦片），模型随应用分发；`vixel doctor` 可自查。

可以对外引用的实测数字（M 系列 Mac，358 段 4K 视频的真实旅行库）：

| 指标 | 数值 |
|---|---|
| 语义搜索（热） | 20–30 ms |
| 图中文字识别覆盖 | 179 / 358 帧识别出文字 |
| 人物 | 16 人，96 张脸自动归类，只把 2 对相似的人交给用户确认 |
| 缩略图生成 | 150 张 2400×1600 JPEG < 5 s |

> 不要对外承诺的：首次**语义**索引速度。实测 EmbeddingGemma 2 约 3.3 s / 张（CPU），1 万张需数小时。
> 文案上说“导入后立刻可浏览，语义索引在后台进行”，不要写“几分钟索引完一万张”。

## 演示脚本（录屏 / 现场）

在演示用的库上先跑一遍，挑稳定命中的查询（用 CLI 先验：`vixel search "<查询>" --json`）：

1. 自然语言：一个**物体**（“西瓜”）+ 一个**场景**（“清真寺”）+ 一个**动作**（“跳舞”）。
2. 图中文字：招牌 / 价签上的词（“微信支付”），结果卡片上会出现“图中文字”角标。
3. 说“没有”：搜一个库里确实没有的东西（“海边”），展示“没有明确匹配”提示。
4. 视频：悬停拖动预览、详情里时间轴高亮命中片段。
5. 人物：人物页 →“是同一个人吗？”→ 合并 → 命名。
6. 离线：断网后重复第 1 步。

截图 / 录屏素材用截图巡检生成，浅色 / 深色各一套，1440×900 窗口：

```bash
npm run build
VIXEL_CAPTURE=./shots VIXEL_CAPTURE_QUERIES="西瓜,微信支付,海边" npx electron . --user-data-dir=<演示库目录>
```

⚠️ **对外素材请用专门的演示库**（无版权问题的照片、得到授权的人像）。个人旅行库里有家人和路人的脸，不能直接公开。

## 发布前必须完成（阻塞项）

- [ ] **签名 + 公证**：`electron-builder.yml` 默认 `notarize: false`；未公证的 DMG 在新版 macOS 上会被 Gatekeeper 拦截。发布构建用
      `electron-builder --mac --c.mac.notarize=true`，并配置 `APPLE_ID` / `APPLE_APP_SPECIFIC_PASSWORD` / `APPLE_TEAM_ID`。
- [ ] **模型随包**：确认 `resources/models` 下有 `gemma2/`、`paddleocr/ppocrv5_dict.txt`（v5 字典，不是 `ppocr_keys_v1.txt`）、人脸模型；DMG 体积约 700 MB，下载页注明。
- [ ] **全新机器冒烟**：新用户目录跑一遍首次使用流程（加文件夹 → 浏览 → 搜索 → 人物）。可用 `--user-data-dir=/tmp/fresh` 模拟。
- [ ] **版本号**：`package.json` 0.2.0 → 发布版本；`CHANGELOG.md` 的 Unreleased 改成版本号 + 日期。
- [ ] **宣传片**：`docs/media/vixel-promo.mp4` 和 README 配图是旧界面的示意画面（旧图标），建议用演示库重录。

## 发布后一周盯什么

- 首次索引卡在哪一步、多久（任务面板 / `vixel doctor`）。
- “没有明确匹配”出现的频率：太高说明门槛 2.5σ 偏严（`RELEVANCE_MIN_Z`）。
- 人脸：非人脸（雕像、画像）被识别成人物的反馈 —— 目前靠用户“隐藏”。

## 已知局限（FAQ 里写清楚）

- 只在 macOS（Apple Silicon）充分测试；Windows / Linux 可构建但 RAW 不支持。
- 长视频只用首帧识别人脸（多帧采样待做）。
- 没有相册 / 收藏 / 编辑：Vixel 是“找”的工具，不替代照片管理软件。
