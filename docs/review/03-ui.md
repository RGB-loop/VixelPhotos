## UX
- **U1 高 无障碍几乎缺失**：网格卡片无 role/tabIndex/aria-selected；浮层无 `role="dialog"`/焦点陷阱；侧边栏行不可 Tab。
- **U2 中 无可见键盘焦点**：加全局 `:focus-visible`。
- **U3 中 主窗口看不到模型缺失状态**：首次运行模型缺失时搜索静默无结果。
- **U4 中 批量操作少**；网格缺 Home/End/PageUp/PageDown。
- **U5 低 不解释命中原因**（语义 / 文字 / 文件名）。
- **U6 低** 重复点击同一侧边栏项会重置密度。
- **U7 低** 日期强制 zh-CN；`--ink-4` 对比度约 2.2:1，用于正文提示不达标。

## 组件设计
App.tsx 706 行仍连贯，可抽出 `useSelection`、`useItemActions`、菜单/键盘接线三块；Sidebar/Toolbar/StatusBar 可 `memo`（需先把内联 lambda 换成 `useCallback`）。
